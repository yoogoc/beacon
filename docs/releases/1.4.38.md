## What's new

- **Two container detail layouts:** the default Container workbench separates ports and resources, health checks, environment variables and volume mounts into categories. Choose Grouped sections in Application settings → Workspace → Container details to view ports and probes together and expand other configuration as needed. Layout changes save automatically and apply immediately to open windows.
- **Clearer container configuration:** image names and versions are separated, ports are shown once, probes show their targets and timing, and empty configuration no longer expands into raw fields. Each container keeps its own selected category and disclosure state when switching layouts.
- **Mouse-friendly scrolling on Windows and Linux:** horizontal scrollbars make overflowing resource tables, details, settings, dialogs and file views accessible without trackpad gestures. Resource tables keep their selection column fixed; application logs can scroll to the longest line even when that line is offscreen. Zoomed workflow canvases also support horizontal scrollbar panning while keeping zoom controls and the minimap clear of the scrollbar.

## 中文说明

- **容器详情双布局：** 默认使用「容器工作台」，按类别查看端口与资源、健康检查、环境变量及卷挂载。可在「应用设置 → 工作区 → 容器详情」切换为「分组折叠」，集中查看端口与探针，其他配置按需展开。布局自动保存，立即应用于已打开的窗口。
- **整理容器配置信息：** 镜像名称与版本分开显示，端口不再重复展示，探针直接呈现检查目标与时间参数，空配置不再铺开原始字段。切换布局时保留各容器独立的分类选择与展开状态。
- **改善 Windows/Linux 鼠标滚动：** 为资源表格、详情、设置、对话框和文件视图补充横向滚动条，无需触控板手势即可查看超出宽度的内容。资源表格保持选择列固定；应用日志即使最长行不在当前可见区域，也能滚动到其末尾。放大的工作流画布支持拖动横向滚动条平移，缩放控件和小地图避开滚动条。
