## What's new

- **Remember window state:** reopening Beacon restores the main window's maximized or fullscreen state.
- **Preserve the ordinary window size:** leaving maximization restores the previous window size. Settings and detached resource windows do not overwrite the main window's saved state.
- **Handle display changes:** restored window dimensions fit the current screen; missing or invalid state falls back to the default window size.

## 中文说明

- **记住窗口状态：** 关闭并重新打开 Beacon 后，主窗口会恢复上次的最大化或全屏状态。
- **保留普通窗口尺寸：** 取消最大化后恢复之前的窗口大小，设置窗口和拆分的资源窗口不会覆盖主窗口记录。
- **适配屏幕变化：** 恢复时根据当前屏幕限制窗口尺寸；记录缺失或无效时使用默认大小。
