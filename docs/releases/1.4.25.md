## What's new

- **Cleaner title bar:** removed the theme shortcut from the top-right corner. Theme controls remain in Settings → Appearance.
- **More complete Simplified Chinese:** filled in missing interface text across resource details, workflow nodes, logs, files, resource comparisons, kubeconfig sources, Helm operations and settings, including menus, native confirmation dialogs and messages containing counts or versions.
- **Consistent language switching:** translated log time-range choices and shortcut descriptions update with the selected language, while canonical selection values, container names and resource identities remain unchanged.
- **Localized section headings:** translate section labels while preserving resource names, hostnames and clickable link destinations.
