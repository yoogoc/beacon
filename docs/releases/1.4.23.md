## What's new

- **Clearer saved filters:** a compact menu shows filter summaries and the current selection, with simpler saving, replacement, search and removal.
- **Reorder columns in the picker:** drag the handles in Visible columns to arrange the table. Hidden columns and filtered choices can also be reordered; changes save automatically while preserving column widths and sorting.
- **Bundled drag handle icon:** includes the icon used by the column picker and drag preview, fixing the missing `icons/grip-vertical.svg` error.
- **Updated README screenshots:** refreshed the English and Chinese documentation to show the current interface.
