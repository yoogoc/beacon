## What's new

- **Cleaner resource toolbars:** resource types stay in the tab title, and the namespace picker moves to the left of the toolbar. Namespace search and multiple selection remain available, with a compact picker in narrow panes.
- **Loading counts:** show a spinner while a resource list loads, then its item count, including `0` for an empty list.
- **YAML line wrapping:** existing-resource and creation editors default to horizontal scrolling. **Wrap lines** toggles wrapping without replacing the draft or undo history.
- **Simpler editing controls:** field suggestions, field help, and schema actions move into the **…** menu. YAML and Data use a theme-colored split **Save** button; its dropdown selects Patch or Server-Side Apply. Saving still requires reviewing the diff first.
- **Optional local validation:** off by default and available through **… → Local validation**, independently of field completion and help. Schema findings are advisory, and disabling validation clears diagnostics and cancels pending checks. Fixed false string-type warnings for Kubernetes `Time` / `MicroTime` fields containing `null` and preserved nullable annotations on schema references.

## 中文说明

- **资源工具栏精简：** 资源类型只在 Tab 标题显示，命名空间选择移到工具栏左侧，保留搜索与多选；窄面板使用紧凑入口。
- **数量加载状态：** 资源列表加载时，数量位置显示旋转动画；完成后显示实际数量，空列表显示 `0`。
- **YAML 换行控制：** 资源详情与创建资源的编辑器默认横向滚动，**Wrap lines** 可切换换行，并保留草稿和撤销记录。
- **编辑操作整理：** 字段补全、字段说明与 Schema 操作收进 **…** 菜单；YAML 和 Data 页使用跟随主题颜色的分体 **Save** 按钮，右侧下拉选择 Patch 或 Server-Side Apply，保存仍需先确认 Diff。
- **本地校验按需启用：** 默认关闭，可通过 **… → Local validation** 开启，字段补全和说明不受影响。Schema 结果仅作提示；关闭会清除诊断并取消待执行检查。修复 Kubernetes `Time` / `MicroTime` 字段为 `null` 时的字符串类型误报，并保留 Schema 引用上的可空标记。
