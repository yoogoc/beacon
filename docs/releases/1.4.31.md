## What's new

- **Accurate macOS window restoration:** reopening Beacon restores its native window state, so a window maximized by double-clicking the title bar keeps its full size. Existing saved window records remain compatible.
- **Paste into Pod shells and debug terminals:** use Cmd+V on macOS, Ctrl+Shift+V or Shift+Insert, or the new right-click Paste action. Unicode and multiline text are supported, with bracketed paste when enabled by the remote application. Ctrl+C and Ctrl+V retain their terminal behavior.
- **Reliable terminal focus:** clicking the terminal grid restores keyboard focus, and pasting from its context menu returns focus to the shell. The keyboard shortcuts guide includes terminal paste commands in English and Simplified Chinese.

## 中文说明

- **精确恢复 macOS 窗口：** 重新打开 Beacon 时恢复原生窗口状态，修复双击标题栏最大化后重启，窗口比最大化略小的问题，兼容已有窗口记录。
- **Shell 和 Debug 终端支持粘贴：** 支持 macOS Cmd+V、Ctrl+Shift+V、Shift+Insert 和右键“粘贴”；支持中文、多行文本，并在远程程序启用时使用括号粘贴模式。Ctrl+C、Ctrl+V 保留原有终端行为。
- **完善终端焦点：** 点击终端恢复键盘焦点，右键粘贴后可继续输入；快捷键指南补充终端粘贴操作，提供英文和简体中文说明。
