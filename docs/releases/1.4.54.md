## What's new

- Pod lists and details now resolve Owner the same way. When a Pod belongs to a ReplicaSet managed by a Deployment, the list shows `Deployment/name`. If the ReplicaSet cannot be read or its UID has changed, the list keeps the original owner reference.
- Pod rows that reference the same ReplicaSet share a lookup. The same display rules apply in the main Pod list, a Node's Pod list, and related-resource tables.

## 中文说明

- Pod 列表和详情页统一了所属资源的解析方式。对于由 Deployment 通过 ReplicaSet 管理的 Pod，列表会显示 `Deployment/名称`。无法读取 ReplicaSet 或其 UID 不匹配时，保留原始所属资源引用。
- 引用同一 ReplicaSet 的 Pod 共用一次查询。Pod 主列表、节点的 Pod 列表和关联资源表格均采用这套显示规则。
