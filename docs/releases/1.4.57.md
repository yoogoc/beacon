## What's new

- Docker configuration Secrets show registry addresses, usernames, and credential types in Overview. Passwords and tokens stay hidden from the summary.
- TLS and Docker configuration Secrets have a dedicated Data tab for viewing and editing their keys. Secret values start hidden.

## 中文说明

- Docker 配置 Secret 的概览会显示镜像仓库地址、用户名和凭据类型，密码和令牌不会在概览中显示。
- TLS 和 Docker 配置 Secret 新增独立的「数据」标签，可查看和编辑键值。Secret 的原始值默认隐藏。
