## What's new

- Hover over the Hosts cell in the Ingress list to see every full hostname. Each hostname has its own copy button, including wildcard hosts.
- Open the resource table's column settings to pin any column to the left or right. Click the selected side again to unpin it. Actions is now in the picker and defaults to the right edge. Pin choices are saved for each cluster context and resource kind.

## 中文说明

- 在 Ingress 列表中，将鼠标移到「主机」单元格即可查看完整域名。每个域名右侧都有独立的复制按钮，通配符域名也可以复制。
- 在资源表格的列设置中，每一列都可以固定到左侧或右侧，再次点击已选方向即可取消固定。「操作」（Actions）列已加入设置，默认固定在右侧。固定位置按集群上下文和资源类型自动保存。
