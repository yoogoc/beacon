## What's new

- **Version-checked saves:** YAML now defaults to saving only edited fields with JSON Patch. Each confirmed save checks the resource UID and resource version, so a replaced or concurrently modified resource is not overwritten.
- **Optional Server-Side Apply:** choose SSA explicitly when field ownership management is needed. Only genuine field ownership conflicts offer a separate, reviewed force-apply action.
- **Clear conflict handling:** ordinary HTTP 409 responses are no longer reported as owner conflicts. Drafts remain intact; **Review latest** carries local edits onto the latest resource for another diff review while preserving unedited live fields.
- **Consistent Data editing:** ConfigMap and Secret Data tabs use the same save methods, review and concurrency checks. Secret values still require Reveal before saving.

## 中文说明

- YAML 默认通过 JSON Patch 只保存修改的字段，并校验资源 UID 和版本，避免覆盖同名替换资源或并发修改。
- Server-Side Apply 改为主动选择；仅真正的字段所有权冲突提供需要再次审阅确认的强制应用操作。
- 普通 HTTP 409 不再误报为 owner 冲突。冲突时保留草稿，可通过 **Review latest** 将本地改动合入最新资源，保留未编辑字段的最新值，再次审阅 diff 后保存。
- ConfigMap／Secret 的 Data 页同步使用相同保存与冲突处理流程；Secret 仍需 Reveal 后才能保存。
