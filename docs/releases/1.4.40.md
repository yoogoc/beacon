## What's new

- **Copy and move resources:** transfer single or selected resources across namespaces and kubeconfig clusters from resource menus, the detail action bar, or the selection toolbar. A separate window guides you through destination and naming, checks and YAML preview, then per-resource results.
- **Review before creating:** check API compatibility, permissions, required configuration references, and server dry-run admission. Rename or skip name conflicts; existing targets are never overwritten. Include missing dependencies explicitly and rewrite references when their target names change.
- **Verified source cleanup:** moves create and verify every target before asking separately to delete reviewed sources. Cleanup checks source UIDs and resource versions, blocks on changed or unready targets, and preserves finalizers. Retry failures without recreating confirmed copies; copied dependencies remain at the source.
- **Secret and migration boundaries:** Secret contents are concealed in previews and require consent before transfer. Generated credentials, persistent storage, and controller-owned children receive specific guidance instead of being treated as ordinary copies. Volume data and external systems are not transferred.

## 中文说明

- **资源复制与移动：** 支持从资源菜单、详情操作栏或多选操作栏，跨 namespace、跨 kubeconfig 集群复制和移动单个或批量资源。独立窗口分为「目标与命名 → 检查与预览 → 执行结果」三步。
- **创建前审阅：** 检查 API 兼容性、权限、必需配置引用及服务端试运行结果。同名冲突可改名或跳过，不覆盖已有目标；缺少的依赖由用户明确加入，依赖改名时同步更新引用。
- **验证后清理源资源：** 移动先创建并验证全部目标，再单独确认删除已审阅的源资源。删除时核对 UID 和 resourceVersion；目标变化或未就绪时阻止清理，不强制移除 finalizer。失败可重试，已确认创建的副本不会重复创建，附带复制的依赖保留在源端。
- **Secret 与迁移范围：** 预览隐藏 Secret 内容，写入目标前需明确确认。生成的凭证、持久化存储及控制器管理的子资源会给出专门提示。卷数据和外部系统不随资源迁移。
