## What's new

- Unified the application identifier as `top.yoogo.Beacon` across standalone and Mac App Store packages.
- Existing preferences, imported kubeconfigs, custom icons and themes, window state, and logs migrate to the new platform directory on first launch. Paths inside saved JSON are updated, existing destination data is preserved, and the previous directory remains as a backup.
- Formal releases now also build a signed universal Mac App Store package and upload it to App Store Connect. Store builds use App Sandbox and receive updates through the Mac App Store; add kubeconfigs using the file chooser or paste a self-contained configuration. External credential plugins and CLI tools remain subject to sandbox permissions.
- Added a Help-menu link to the bilingual Beacon privacy policy.
- Application bundles now include `© 2026 Beacon Team` in their copyright metadata.
