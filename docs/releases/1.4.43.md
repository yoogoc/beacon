## What's new

- **Copy a kubectl shell command:** choose Copy command beside Open a shell to copy `kubectl exec -it` for the current Pod, namespace, container, context, and command without opening a remote session. An empty command retains the bash-to-sh fallback.
- **Kubeconfig sources and quoting:** commands for added sources include their durable kubeconfig path and original context name. If a source is unavailable, Beacon asks you to restore it before copying. Arguments with spaces and quotes are escaped for POSIX shells on macOS / Linux and PowerShell 7.3+ on Windows; kubeconfig credential contents are not embedded in the copied command.
- **Compact launcher:** the open and copy actions wrap in narrow panes, with a localized copy confirmation and English / Simplified Chinese labels.

## 中文说明

- **复制 kubectl 终端命令：** 在「Open a shell」旁点击「复制命令」，生成当前 Pod、namespace、容器、context 与输入命令对应的 `kubectl exec -it`，不启动远端连接。输入为空时保留 bash → sh 回退逻辑。
- **来源与参数转义：** 额外添加的 kubeconfig 来源会附带持久化文件路径与真实 context 名称；来源不可用时提示恢复后再复制。含空格、引号的参数会正确转义，macOS / Linux 使用 POSIX Shell 格式，Windows 使用 PowerShell 7.3+ 格式；不会将 kubeconfig 凭证内容写入复制命令。
- **适配窄窗口：** 打开与复制按钮在窄面板中自动换行，支持复制成功提示及中英文界面。
