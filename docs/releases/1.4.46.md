## What's new

- **Floating file loading:** directory and file reads now display an animated loading card over the file area, keeping the current list and preview layout stable instead of adding a Working bar above them. Cancellation remains available; uploads and downloads retain their transfer progress display.
- **Animated first load:** entering Pod files now shows a rotating central loading indicator. Loading states clear when a read completes or is cancelled. Switching containers safely shows the loading view until the new directory is available.

## 中文说明

- **文件加载浮层：** 读取目录和文件时，在文件区域内显示带动画的悬浮加载提示，保持现有列表及预览布局稳定，替代顶部新增的 Working 横条。保留取消操作，上传和下载继续显示传输进度。
- **首次加载动画：** 首次进入 Pod files 时，中央加载指示器会旋转。读取完成或取消后清除加载状态；切换容器时，目录尚未就绪也能正确显示加载视图。
