## What's new

- **Adaptive network paths:** compact resource cards wrap to fit the detail panel, with the current resource highlighted and longer explanations available on demand.
- **Data in Overview:** ConfigMap and Secret values now open directly in Overview. The separate Data tab is removed; resource metadata remains available through Resource details, while search, highlighting, resizing, drafts, and reviewed saves are preserved.
- **Cleaner key editing:** delete or restore a key from its list item, with a compact value toolbar. Secret values still require explicit reveal before editing or deletion.
- **Refined connection dialogs:** port forwarding checks its configured target when opened. Port-forward and Debug forms use compact layouts, with advanced debug options collapsed by default.
- **Reliable debug terminals:** Enter and Escape are routed to the terminal instead of dismissing its dialog. Debug shells start interactively with color environment variables, and non-zero exits retain their diagnostics. Startup now reports runtime failures, limits status-request waits, and supports stopping and retrying the wait.

## 中文说明

- **自适应网络路径：** 使用紧凑资源卡片，随详情面板宽度自动换行，高亮当前资源，详细说明按需查看。
- **Overview 直接显示 Data：** ConfigMap 和 Secret 的数据合并到 Overview，移除独立 Data 标签；元数据通过“资源详情”查看，保留搜索、高亮、拖拽调整高度、草稿及保存前对比。
- **精简 key 编辑：** 在 key 列表项内删除或恢复键值，编辑栏改为紧凑布局。Secret 仍需主动显示内容后才能编辑或删除。
- **重做连接弹窗：** 端口转发打开时自动检查目标，端口转发和 Debug 使用紧凑布局，Debug 高级选项默认收起。
- **修复 Debug 终端：** Enter 和 Escape 交给终端处理，避免弹窗被意外关闭；Shell 使用交互模式并设置颜色环境变量，保留异常退出信息。启动时显示运行时错误，限制状态请求等待时间，并支持停止等待和重试。
