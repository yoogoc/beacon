## What's new

- **Terminal Tab completion:** Tab now reaches the focused shell instead of moving focus to controls outside the terminal. Shift+Tab is also sent to the terminal, including in debug terminal dialogs.
- **Focus-aware keyboard handling:** search fields and toolbar controls retain ordinary Tab navigation, and Ctrl+Tab still switches resource tabs. In-progress IME composition is kept local. The shortcut guide includes English and Simplified Chinese descriptions for the terminal Tab bindings.

## 中文说明

- **修复终端 Tab 补全：** 终端获得焦点时，Tab 交给 Shell 处理，不再跳到外部控件；Shift+Tab 同样发送到终端，Debug 终端弹窗也适用。
- **区分终端与控件焦点：** 搜索框和工具栏仍能通过 Tab 正常切换焦点，Ctrl+Tab 保留资源标签切换功能；输入法正在组合的文本不会发送到远端。快捷键指南补充了终端 Tab 绑定的中英文说明。
