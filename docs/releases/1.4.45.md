## What's new

- **Floating line previews:** hover over a file or log line to view formatted contents with syntax highlighting. Pin the preview, toggle wrapping, switch to the original text, or copy either representation. File previews render visible rows, while structured parsing runs in the background with size and nesting limits.
- **More structured formats:** recognize JSON, YAML, XML, logfmt, common key/value assignments, and URL query parameters. Preserve original text for copying and fall back to it when a format cannot be reliably recognized. Keep repeated fields and query parameters; preserve XML mixed content and CDATA.
- **Log details in one popover:** hovering works in the default compact log workspace, including wrapped lines. The left-hand inspect button opens and pins the same popover instead of the bottom details panel. Exact field filtering and bookmarks remain available in its Fields tab, and opening the popover keeps the log canvas size unchanged.

## 中文说明

- **逐行悬浮速览：** 悬停文件或日志行后，浮层以语法高亮显示格式化内容，支持固定、换行、切换原文及分别复制。文件预览按可见行渲染，结构解析在后台完成，并限制预览大小及嵌套层级。
- **多种格式识别：** 支持 JSON、YAML、XML、logfmt、常见键值对及 URL 查询参数。保留可复制的原始文本，无法可靠识别时回退原文；保留重复字段和查询参数，以及 XML 混排文本与 CDATA。
- **统一日志详情入口：** 默认简洁日志视图和换行模式均可悬停打开浮层；左侧查看按钮改为打开并固定同一浮层，替代底部详情面板。字段精确筛选和收藏保留在「字段」页中，打开浮层不再挤压日志区域。
