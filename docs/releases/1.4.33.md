## What's new

- **Cleaner terminal exit state:** ended sessions use a compact status bar with a clear Reconnect action. Shell command options stay collapsed until needed, and inactive cursors disappear. Output remains available for search, selection, and copying.
- **Stop debug containers:** the Debug window and Pod overview offer a confirmation before stopping a supported debug container. Beacon requests a cooperative exit and verifies the container's terminated status; it does not delete the Pod or signal application processes. The terminal transcript stays available, with reconnect disabled after the container stops.
- **Clear compatibility and errors:** safe stopping applies to debug containers newly created by this version. Existing containers cannot gain the capability retroactively, and ephemeral-container records remain until the Pod is replaced. Replaced Pods, permission errors, and stop timeouts are reported without claiming success. New controls and messages support English and Simplified Chinese.

## 中文说明

- **精简终端退出状态：** 会话结束后显示紧凑状态栏和明确的“重新连接”操作，Shell 命令选项按需展开，并隐藏失效光标。历史输出仍可搜索、选择和复制。
- **停止调试容器：** Debug 窗口和 Pod 概览新增停止入口，操作前确认目标。Beacon 请求调试容器自行退出，并核实其已终止；不会删除 Pod 或向业务进程发送信号。停止后保留终端输出，并禁用重新连接。
- **明确兼容范围与错误：** 安全停止仅支持此版本新创建的调试容器，旧容器无法追补；临时容器记录仍保留至 Pod 被替换。Pod 已替换、权限不足或停止超时均会明确提示，不会误报成功。新增操作和文案支持英文与简体中文。
