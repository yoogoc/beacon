## What's new

- **Multiple Pod sessions:** keep several Pods open in bottom-panel tabs. Opening another Pod no longer replaces the existing logs or terminal; switching tabs retains each session's container, search, filters, pause, wrapping and scroll position. Sessions also survive namespace and resource navigation.
- **Side-by-side logs:** compare two Pod sessions with independent controls and a draggable divider. Choose the right-hand Pod from the session menu, or return to a single pane without closing either session. Narrow windows arrange the panes vertically.
- **Compact log controls:** keep container selection, search, level filtering and pause within reach. Advanced filters are available on demand; wrapping, timestamps, previous-container logs and export are grouped in a menu. Search for another Pod from the plus button and press Enter to open the first match.
- **Safer session closing:** closing a session disconnects only that Pod's tools, with confirmation for a running command or shell. Pods with the same name in different namespaces, or recreated with a different UID, keep separate sessions.

## 中文说明

- **多 Pod 会话标签：** 底部面板支持同时保留多个 Pod。打开新 Pod 不再替换已有日志或终端；切换标签时保留各会话的容器、搜索、筛选、暂停、换行与滚动位置。切换命名空间或资源类型也会保留会话。
- **并排查看日志：** 两个 Pod 使用独立的日志控制栏，支持拖动分隔线调整宽度、通过菜单选择右侧 Pod，以及返回单面板而不关闭会话。窄窗口自动改为上下排列。
- **精简日志工具栏：** 常用的容器选择、搜索、日志级别与暂停直接显示，高级筛选按需展开；换行、时间戳、上一个容器的日志和导出收进菜单。通过加号搜索其他 Pod，按 Enter 打开首条匹配结果。
- **完善会话关闭行为：** 关闭标签只断开对应 Pod 的工具；存在运行中的命令或终端时先确认。不同命名空间的同名 Pod，以及 UID 变化后重建的 Pod，分别保留会话。
