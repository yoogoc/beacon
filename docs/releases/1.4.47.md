## What's new

- **Refresh detected updates:** opening Updates after a new release has been detected now checks again for the latest version. This works from the update badge, the settings sidebar, and an existing settings window. Repeated opens reuse a pending check; downloads, ready-to-install updates, and installation keep their current state.

## 中文说明

- **重新检查已发现的更新：** 检测到新版本后，打开 Updates 页面会再次检查最新版本。从更新标识、设置侧栏或已有设置窗口打开均可生效。重复打开会复用正在进行的检查，下载、待安装及安装中的状态会保留。
