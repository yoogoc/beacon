## What's new

- **Wait for container logs:** opening logs before a container starts shows a waiting indicator and retries automatically. Export becomes available when the log request succeeds. Closing the pane or changing containers cancels pending requests; permission failures, invalid container names and other real errors remain visible.
- **Single-line bulk restart names:** namespace and Deployment names no longer wrap in the confirmation dialog. The namespace column is wider, headings and rows align, and long names show an ellipsis with the complete name available on hover and through Copy.

## 中文说明

- **等待容器日志就绪：** 容器尚未启动时打开日志，显示等待动画并自动重试；日志请求成功后恢复导出。关闭日志页或切换容器会取消等待，权限不足、容器名称无效等真实错误仍正常提示。
- **批量重启名称保持单行：** 确认弹窗中的命名空间和 Deployment 名称不再换行，加宽命名空间列并对齐表头、列表。超长名称显示省略号，悬停或使用“复制”可获取完整内容。
