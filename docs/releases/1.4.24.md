## What's new

- **English and Simplified Chinese:** Beacon follows the system language by default and uses English for unsupported languages. Choose a language in Settings → Appearance → Language.
- **Switch instantly:** the language preference saves automatically and updates existing windows and application menus immediately, while keeping connections, editing drafts, filters and column layouts.
- **Localized navigation and tools:** translated interface text, shortcuts, command search, settings and resource actions. Resource names, Kubernetes kinds and fields, YAML, raw logs and diagnostic details retain their original values.

## 中文说明

- **支持英文和简体中文：** 默认跟随系统语言，不支持的语言回退为英文。可在「应用设置 → 外观 → 语言」中切换。
- **切换立即生效：** 自动保存语言偏好，同步更新已打开的窗口和应用菜单，保留集群连接、编辑草稿、筛选及列布局。
- **界面与工具本地化：** 翻译导航、快捷键、命令搜索、设置及资源操作等界面文案；资源名称、Kubernetes 类型与字段、YAML、原始日志和诊断详情保留原值。
