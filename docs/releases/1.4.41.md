## What's new

- **Resource export:** select resources and choose Export in the selection toolbar. One resource saves as YAML; multiple resources save as a compressed ZIP containing one YAML file per resource. Filenames include resource kind, namespace, and name, with automatic disambiguation for collisions.
- **Full manifests:** export reads the selected resources from the cluster instead of relying on list-row summaries. Resource data, including original Secret values, is retained; verbose managed-field history is omitted. Selection and connection are captured before choosing a save location, so navigating to another resource list does not change the export.
- **Complete files only:** a failed read or a resource replaced after selection leaves the destination file intact. Export writes to a temporary file and replaces the chosen destination only after the entire export succeeds. Cancelling the save dialog does not start resource reads. The action supports compact layouts and English / Simplified Chinese.

## 中文说明

- **批量资源导出：** 勾选资源后，点击多选操作栏的「导出」。单个资源保存为 YAML，多个资源分别生成 YAML 后压缩为 ZIP。文件名包含资源类型、namespace 与名称，重名时自动区分。
- **读取完整内容：** 导出时从集群重新读取资源，不使用列表中的精简数据。保留资源数据及 Secret 实际值，省略冗长的 managedFields 历史。打开保存对话框前固定选中资源及连接，切换资源列表不会改变本次导出内容。
- **完整写入后保存：** 任一资源读取失败或选中后被重建时，保留已有目标文件。先写临时文件，全部成功后再替换目标；取消保存对话框不会开始读取资源。支持窄窗口布局及中英文界面。
