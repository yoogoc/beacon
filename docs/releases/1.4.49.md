## What's new

- **Export cluster kubeconfigs:** right-click a cluster and choose **Export cluster…** to save a standalone YAML for that context, including its cluster, user, and default namespace. Exports use the selected kubeconfig source, including when different sources contain identically named contexts, and work without connecting to the cluster.
- **Portable connection data:** referenced CA certificates, client certificates, private keys, and token files are embedded in the exported YAML. EKS and other authentication plugin settings are preserved without running the plugin during export. Atomic saves leave an existing destination intact if export fails; exported files use owner-only permissions on Unix.

## 中文说明

- **导出集群 kubeconfig：** 右键集群并选择 **导出集群…**，即可将所选 context 及其集群、用户和默认 namespace 保存为独立 YAML。导出使用所选 kubeconfig 来源，支持不同来源下的同名 context，无需连接集群。
- **内嵌连接数据：** 自动将引用的 CA 证书、客户端证书、私钥和 token 文件内嵌到导出 YAML。保留 EKS 等认证插件配置，导出时不执行插件。采用原子保存，导出失败时保留已有目标文件；Unix 下导出文件仅允许当前用户读写。
