## What's new

Beacon 1.4.14 adds the following cluster operations and inspection tools:

- **Configuration usage:** inspect which Pods and workloads reference a ConfigMap or Secret, including keys, environment variables and mounts; identify missing references and review impact before editing or deleting.
- **Structured logs:** inspect JSON/logfmt fields, filter levels and fields, use regex searches and time ranges, bookmark lines and export filtered results.
- **Jobs and CronJobs:** run schedules immediately, suspend/resume schedules and rerun Jobs as new executions, with reviewed actions and links to execution status, Pods and logs.
- **Helm inspection:** view values, manifests and revision history, and compare revisions.
- **Node maintenance:** review cordon/uncordon and drain actions, inspect Pod disruption budgets and local storage, and track eviction results.
- **YAML assistance:** use connected-cluster OpenAPI and CRD schemas for field completion, enum values, documentation, required fields and inline validation.
- **Resource metrics:** view Pod, Node and container CPU/memory trends, requests/limits and restart/OOM markers, using Metrics API session samples or Prometheus history.
- **Argo Workflows:** submit templates with reviewed parameters; retry, resubmit, suspend/resume, stop and terminate workflows through state-aware actions.
- **Permissions:** query access for the current user, ServiceAccounts, users and groups; inspect Binding → Role → Rules and investigate forbidden requests.
- **Global search and favorites:** search across connected clusters, resource kinds and namespaces, and save cluster/resource favorites.
- **Port forwarding:** configure local ports for Pods, Services and Deployments, save and explicitly restore presets, and select replacement backend Pods while keeping the local port.
- **Helm operations:** review chart versions, values and rendered differences before installation or upgrade; rollback or uninstall with progress and refreshed release history.

### Usage notes

- Helm installation, upgrade, rollback and uninstall require a local Helm CLI (3.13+ or 4.x). Read-only Helm inspection does not require it.
- Metrics API provides samples collected during the current view session; historical queries use the configured Prometheus source.
- Argo retry/resume operations report an explicit limitation when node status is stored only in an external Argo offload database.
- Saved forwards start only through Restore. Existing TCP connections must reconnect after a backend Pod is replaced.

本版本完成 P1、P2 的 12 项功能：配置引用关系与缺失引用检查、结构化日志、Job/CronJob 操作、Helm 详情与版本对比、Node 维护、YAML Schema 智能编辑、单资源指标趋势、Argo Workflows 运行操作、RBAC 权限查看与解释、跨集群搜索与收藏、端口转发增强，以及 Helm 安装、升级、回滚和卸载。
