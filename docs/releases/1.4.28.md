## What's new

- **More cluster colors:** generate a wider range of hues as clusters are added, avoiding the previous four-color cycle.
- **Consistent cluster identity:** each cluster uses the same color in the sidebar and its resource tabs.
- **Theme-aware readability:** balance color brightness for light and dark themes so different hues remain easy to see.

## 中文说明

- **丰富集群配色：** 随集群数量增加持续生成分散的新颜色，避免原先每四个集群就重复一次的配色。
- **保持集群标识一致：** 同一集群在侧栏图标和资源标签页中使用相同颜色。
- **适配浅色和深色主题：** 平衡不同色相的亮度，让各类颜色都更清晰易辨。
