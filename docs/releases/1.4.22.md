## What's new

- **Progressive resource lists:** resources appear as pages arrive, with 100 items requested per page. The loaded count stays visible alongside a loading indicator, and partial results remain searchable while later pages load.
- **Adaptive workflow canvas:** execution graphs fit the available space, group large branches, and provide search, zoom, pan, and a minimap. Successful nodes no longer repeat their status text beside the status icon.
- **Smoother nested scrolling:** scrolling workflow details or update release notes stays within the inner panel.
- **Cleaner filters:** namespace and label menus show fewer instructions; label selector syntax is available from a small help icon.

## 中文说明

- **资源列表边加载边显示：** 每页请求 100 条，已到达的资源立即显示；数量与加载动画同时保留，后续页加载期间可搜索已有数据。
- **自适应工作流画布：** 执行图适应可用空间，支持大分支分组、搜索、缩放、平移和缩略导航；成功节点不再在状态图标旁重复显示状态文字。
- **修复嵌套滚动：** 滚动工作流详情或更新说明时，外层页面不再跟随滚动。
- **精简筛选提示：** 移除命名空间与标签菜单的多余说明，标签选择器语法通过小图标悬浮查看。
