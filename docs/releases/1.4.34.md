## What's new

- **Quiet file browsing on Windows:** hide the local kubectl console when container file operations fall back from WebSocket exec. Opening folders, previewing files, and transferring files no longer launch a visible console for each fallback command.

## 中文说明

- **修复 Windows 文件浏览弹黑框：** 容器文件操作从 WebSocket exec 回退到本机 kubectl 时隐藏控制台，避免打开目录、预览和传输文件时反复弹出黑色窗口。
