## What's new

- **Redesigned Data tabs:** ConfigMaps and Secrets now have a searchable key list and a focused value editor, arranged side by side in wide panes or vertically in narrow panes.
- **Large key lists:** render only visible rows and load editors and syntax analysis on demand. A bounded editor cache keeps browsing responsive while preserving unsaved drafts.
- **Whole-entry deletion:** **Delete key** stages removal of a text or binary key/value pair; **Restore key** undoes it. Review edits and deletions together before confirming a version-checked Patch. Secret values still require **Reveal** before editing, deleting, or saving.
- **Readable long values:** horizontal scrolling is now the default, with a **Wrap lines** toggle shared across keys in the current detail view. Content-aware highlighting, folding, draggable height, and draft undo history are preserved.
- **Documentation:** refreshed the English and Chinese READMEs with implemented features, YAML and Data editing flows, and development checks.

## 中文说明

- ConfigMap / Secret 的 Data 页改为可搜索的 Key 列表与单值编辑区，宽面板左右展示，窄面板上下展示。
- 列表仅渲染可见行，编辑器与语法分析按需加载；限制编辑器缓存数量，同时保留未保存的草稿，改善 Key 较多时的性能。
- **Delete key** 可将整项文本或二进制 Key / Value 标记为待删除，**Restore key** 可撤销；修改与删除统一审阅差异，确认后使用带版本校验的 Patch 提交。Secret 仍需 **Reveal** 后才能编辑、删除或保存。
- 长行默认横向滚动，**Wrap lines** 可切换自动换行，并在当前详情中切换 Key 时沿用；保留内容高亮、代码折叠、拖拽高度与草稿撤销记录。
- 同步更新中英文 README，补齐已实现功能、YAML / Data 编辑流程与开发检查命令。
