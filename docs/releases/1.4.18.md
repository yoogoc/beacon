## What's new

- **ServiceAccount token Secrets:** show the associated ServiceAccount with a resource link, token population state, and legacy-token usage or invalidation metadata in Overview.
- **Purpose-built Data details:** inspect decoded JWT headers and claims, namespace references, and CA certificate bundles. Secret values still require **Reveal**, and **Raw value** remains available for editing. JWT decoding is local and does not verify the signature or authenticate the token.
- **Responsive, current details:** analyze only opened and revealed values in the background, refresh controller-populated data, and preserve unsaved drafts.
- **Quieter update checks:** check at startup and every hour when enabled. Automatic check failures are logged and retried on the next interval; manual checks continue to show errors. A manual request can reuse an ongoing background check.

## 中文说明

- **ServiceAccount Token Secret：** Overview 展示关联的 ServiceAccount 并支持跳转，同时显示 Token 填充状态，以及旧式 Token 的使用和失效标记。
- **专属 Data 详情：** 支持查看 JWT Header 与 Claims、Namespace 引用和 CA 证书链；仍需 **Reveal** 才能查看敏感内容，可切换 **Raw value** 编辑原值。JWT 仅在本地解码，不验证签名或进行身份认证。
- **性能与数据刷新：** 仅对打开且已揭示的值进行后台解析，控制器填充数据后可刷新详情，同时保留未保存的草稿。
- **更新检查优化：** 启用自动检查时，启动后检查一次，此后每小时检查。后台检查失败仅记录日志，并在下次周期重试；手动检查仍显示错误，也可复用正在进行的后台请求。
