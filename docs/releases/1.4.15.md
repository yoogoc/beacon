## What's new

- **Selection toolbar:** checked resource actions now appear on a separate row below the filters, directly after the selected count. Search and filters keep their space, including in narrow panes.
- **Bulk Deployment restart:** review namespaces and resource names before restarting selected Deployments. Each target shows its own result; successful targets are deselected and failed targets remain selected when still available.
- **Restart checks:** verify each target's permissions and selected UID, reject paused or terminating Deployments, and preserve the current Pod template and update strategy.
- **Release pipeline:** build platform packages alongside checks and reuse publisher tools from the Linux build. Publication still requires all checks and platform packages to succeed.
- **Release publication:** verify and use the pushed version tag directly, avoiding workflow-permission errors when the main branch advances during packaging.
