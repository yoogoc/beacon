## What's new

- **Pod owner and IP columns:** Pod lists now show **Owner** and **Pod IP** immediately after **Containers**. Owner displays the controlling resource as `Kind/name`, and Pod IP supports IPv4 and IPv6. Missing values use the standard placeholder.
- **Saved layout compatibility:** the new columns are inserted after Containers in existing saved layouts, preserving the relative order of existing columns and their visibility, widths, and sort settings.

## 中文说明

- **Pod 列表新增所属资源与 IP：** 在 **Containers（容器）** 后依次显示 **Owner（所属资源）**、**Pod IP**。Owner 优先显示控制该 Pod 的资源，格式为 `类型/名称`；Pod IP 支持 IPv4、IPv6，缺失值使用统一占位。
- **兼容已保存的列布局：** 新列会插入 Containers 后面，保留已有列的相对顺序、显隐、宽度与排序设置。
