## What's new

- **Select and copy terminal text:** Pod shells and debug terminals support drag selection, double-click word selection, triple-click line selection, and Alt-drag rectangular selection. Copy from the keyboard or the context menu.
- **Browse and search terminal history:** scroll through output with the mouse, scrollbar, or keyboard. Find text across the screen and scrollback with Cmd+F on macOS or Ctrl+Shift+F on Windows and Linux, then jump between highlighted matches.
- **Clearer text and native input:** terminal fonts follow application settings, with font-size controls, improved wide-character alignment, and native input-method composition for Chinese and other languages.
- **Better terminal application controls:** function keys, modified navigation keys, mouse reporting, alternate-screen scrolling, and focus events follow terminal modes. Hold Shift to select text while an application captures the mouse. F1 reaches the focused terminal instead of opening the application shortcut guide.

## 中文说明

- **终端选区与复制：** Pod Shell 和 Debug 终端支持拖选、双击选词、三击选行、Alt 拖动矩形选区，可通过快捷键或右键菜单复制。
- **历史滚动与搜索：** 支持滚轮、滚动条拖动及键盘翻页；macOS 使用 Cmd+F，Windows 和 Linux 使用 Ctrl+Shift+F，搜索当前屏幕及历史输出，高亮并跳转匹配项。
- **改善文字显示与输入：** 终端字体跟随应用设置，可调整字号，优化中文等宽字符对齐，支持中文等语言的原生输入法组合输入。
- **完善终端程序操作：** 按终端模式处理功能键、组合导航键、鼠标事件、替代屏幕滚动及焦点事件；程序接管鼠标时按住 Shift 仍可选择文字。终端获得焦点时，F1 正确传入终端。
